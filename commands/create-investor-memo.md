# Command — /create-investor-memo

## Purpose

Produce a structured property investor memo that consolidates all analysis and preparation from across the Property File into a single decision document.

## Use when

You have run at least Listing Analysis + Cash Flow + Due Diligence and want to consolidate everything before your broker and accountant conversations, or before deciding to buy, wait, or walk away.

## Inputs required

The user pastes their current Property File (or provides the key outputs from prior skills).

## Steps

1. Read the full Property File provided
2. Consolidate into the investor memo format
3. Identify the open questions and red flags still unresolved
4. Return the memo with a DECISION LOG entry ready to complete

## Output format

See [property-investor-memo.md](../report-templates/property-investor-memo.md)

## Disclaimer

This memo is general information and preparation only. Not financial, credit, legal, or tax advice. All decisions require professional review.
